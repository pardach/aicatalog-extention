# 🎨 Vector Catalog Extension for Adobe Illustrator

یک اکستنشن قدرتمند CEP برای مدیریت و سازماندهی طرح‌های وکتوری در Adobe Illustrator.

## ✨ ویژگی‌های اصلی

### 🚀 ثبت سریع طرح‌ها
- **ثبت خودکار**: تبدیل انتخاب‌ها به Symbol با کد منحصر به فرد
- **ثبت گروهی**: ثبت چندین طرح به صورت همزمان
- **تولید کد خودکار**: بدون نیاز به نام‌گذاری دستی

### 🏷️ مدیریت برچسب‌ها و خانواده‌ها
- **سیستم خانواده**: هر طرح "گل" نماینده یک خانواده است
- **برچسب‌گذاری هوشمند**: مدیریت برچسب‌ها با امکان ادغام و حذف
- **اتصال چندگانه**: هر طرح می‌تواند به چندین خانواده تعلق داشته باشد

### 🔍 جستجو و فیلتر پیشرفته
- **جستجوی هوشمند**: بر اساس کد، برچسب، خانواده و توضیحات
- **فیلترهای چندگانه**: نوع، اندازه، دوره زمانی
- **نمایش فوری**: نتایج فوری با پیش‌نمایش

### 📊 مدیریت داده‌ها
- **ذخیره دوگانه**: SQLite برای جستجو + Symbol Notes برای پشتیبان‌گیری
- **همگام‌سازی**: همگام‌سازی خودکار بین پایگاه داده و فایل
- **Export/Import**: پشتیبان‌گیری و بازیابی کامل

### 🎯 قراردهی و چیدمان
- **Place هوشمند**: قراردهی طرح‌ها با تنظیمات پیشرفته
- **چیدمان خودکار**: Grid، Random، Spiral و Custom
- **مدیریت لایه‌ها**: ایجاد لایه‌های جداگانه برای هر طرح

## 🛠️ نصب و راه‌اندازی

### پیش‌نیازها
- Adobe Illustrator CC 2018 یا بالاتر
- Windows 10/11 یا macOS 10.14+

### مراحل نصب
1. **دانلود**: کلون کردن ریپازیتوری
```bash
git clone https://github.com/pardach/aicatalog-extention.git
```

2. **نصب**: اجرای فایل نصب
```bash
# Windows
install.bat

# macOS
./install.sh
```

3. **فعال‌سازی**: 
   - باز کردن Illustrator
   - رفتن به `Window > Extensions > Vector Catalog`

## 📖 راهنمای استفاده

### ثبت طرح جدید
1. انتخاب آیتم در Illustrator
2. کلیک روی "ثبت انتخاب"
3. طرح به صورت خودکار ثبت می‌شود

### جستجو و فیلتر
1. استفاده از نوار جستجو
2. انتخاب فیلترهای مورد نظر
3. مشاهده نتایج فوری

### مدیریت خانواده‌ها
1. کلیک روی "صفحه خانواده"
2. انتخاب خانواده مورد نظر
3. مشاهده تمام اعضای خانواده

## 🧪 تست و عیب‌یابی

### فایل‌های تست
- `test-fixes.html`: تست جامع عملکرد


## 🔧 توسعه

### ساختار فنی
- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Backend**: ExtendScript (Adobe's JavaScript)
- **Database**: SQLite با sql.js
- **Framework**: CEP (Common Extensibility Platform)
