# فولدر توسعه (Development)

این فولدر شامل فایل‌های آزمایشی، دیباگ و توسعه است که برای تست و توسعه اکستنشن استفاده می‌شوند.

## فایل‌ها:

### ExtendScript Tests
- `test-*.jsx` - فایل‌های تست ExtendScript
- `debug-extendscript.js` - ابزارهای دیباگ ExtendScript
- `extendscript-debug.jsx` - دیباگر ExtendScript

### JavaScript Tests
- `test-*.js` - فایل‌های تست جاوااسکریپت
- `test-connection-details.js` - جزئیات تست اتصال

### HTML Debug Tools
- `*-debug.html` - صفحات HTML برای دیباگ
- `dev-access.html` - ابزار دسترسی توسعه

## نکات:
- این فایل‌ها در نسخه نهایی اکستنشن حذف خواهند شد
- برای توسعه و تست از این فایل‌ها استفاده کنید
- تغییرات در این فایل‌ها روی عملکرد اصلی اکستنشن تاثیر نمی‌گذارد
