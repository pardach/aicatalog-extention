اکستنشن اصلی:
cep://com.yourcompany.newextension.panel/

http://localhost:9222
Debug لوکال (این فایل):
http://localhost:8206/debug-local.html
اکستنشن لوکال (اگر سرور اجرا باشد):
http://localhost:8206/index.html

📋 راه‌اندازی Debug

  1. سرور لوکال را اجرا کنید:
    2. cd new-illustrator-extension
    python -m http.server 8000
  2. یا با Node.js:
    3. npx http-server -p 8000
  3. فایل .debug را چک کنید
  4. Illustrator را با debug mode باز کنید
  5. اکستنشن را از منوی Window باز کنید
🔍 تست اتصال سرور 🚀 باز کردن اکستنشن لوکال 📱 باز کردن اکستنشن اصلی 🛠️ Chrome DevTools

🔧 ابزارهای Debug

ابزارهای موجود در اکستنشن برای debug و مانیتورینگ:

  • 🐛 Debug Panel: نمایش real-time logها
  • 🧪 تست خودکار: بررسی اتصال و عملکرد
  • ⚡ Performance Monitoring: اندازه‌گیری زمان عملیات‌ها
  • 🚨 Error Notifications: نمایش خطاها به کاربر
  • 📊 Memory Usage: تخمین مصرف حافظه

💡 نکات Debug

  • Console مرورگر را باز کنید (F12)
  • برای دیدن ExtendScript logs، ExtendScript Debugger را باز کنید
  • در صورت مشکل، تست‌ها را اجرا کنید (دکمه 🧪)
  • Debug Panel را فعال کنید (دکمه 🐛)
