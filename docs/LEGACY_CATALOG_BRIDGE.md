# Legacy catalog bridge
Requires matching Setoffline branch and opt-in legacy bridge flag. Catalog shows source. Existing-family preflight returns occupied roles, provider and snapshot; select a family from search, review members and append only unoccupied roles. Snapshot is persisted in publication request for safe retry. If changed, repeat preflight before submission. New members live in Studio catalog; external originals remain read-only. Legacy SVG retrieval only when server offers it and export permission allows; server validates explicit units, matching metadata and safe content, limits to 1 MiB. Raster images are not vectorized. Existing-family browsing is not proof of eligibility; ambiguous source or role blocks append. Full Illustrator and concurrent provider-sync tests remain required.
