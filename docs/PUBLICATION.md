# Batch publication client

Requires operations.upload and studio_catalog in server capabilities. Create request_id once via newPublicationId(); pass a fully reviewed payload with mode, family_key, family_name, reservation_id as applicable and items built by review model. A new family requires a matching active reservation. Existing family must be Studio-owned; standalone cannot be flower. Server generates authoritative names and validates SVG. Up to 40 items / 16 MiB decoded / 24 MiB JSON subject to server limit. Preserve identical payload and request ID on uncertain network failure; do not create a new ID or reserve another number until outcome is known. No automatic retries, no durable queue or visible panel yet. Do not enable in production before server/client integration and Illustrator fixture tests. Run node tests/publication.test.js.
