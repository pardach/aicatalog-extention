# Phase 5 review panel and personal upload

Panel is inserted above the legacy catalog, leaving existing local flows intact. Open details, enter exact HTTPS origin, issue temporary browser token, connect, choose independent selection or family group, extract, edit common family/tags and per-row content/kind/role, confirm, upload. Search content tags from server and page results. Family suggestions show first 100; arbitrary family key can be entered. Sequential in-memory queue, per-row success/failure and manual retry; successful rows excluded, token not persisted. Reconnecting to different account/origin with nonempty queue refused. No durable queue/resume after Illustrator closes; aggregate extraction memory limit and cancel remain release gates. No public upload. Server requires two flags and permission. Strict vector SVG gate may reject some native Illustrator exports; no silent raster conversion. Actual CEP panel tests, native export fidelity, HTTP integration and permission tests required. No production change.
