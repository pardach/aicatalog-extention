# Roundtrip Illustrator workflow
Catalog family lookup uses exact family filter and pagination. Studio-owned authorized SVG may be previewed as a restricted img data URL, saved or opened in Illustrator and duplicated into nested editable member groups. Batch download sequentially, hash verified, max 40 members/16 MiB total, each existing download limit 1 MiB. User confirms destination active document after download. Host checks visible bounds with 0.15 pt tolerance, uses row layout without scaling, rejects if not fitting artboard, removes newly created root group on failure. Actual Illustrator cross-document duplication, layer ordering, colors, clipping and rollback must be validated. No external-provider download, no automatic resizing. Metadata editor sends revision with changes; server rejects stale edits; structure, dimensions and file remain unchanged. Preview is on demand only and requires export.print, not a public thumbnail service. No destructive replacement/delete.
